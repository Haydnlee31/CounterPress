# Explore Footie

[Open Footie](https://counterpress.icyplant-0eb80d8e.eastus.azurecontainerapps.io/) · [Watch the 1:59 demo](https://www.youtube.com/watch?v=vqpPXBcn0R0)

The public app requires no sign-in, API key or local setup. Use a current desktop browser for the full pitch-and-specialists layout; mobile presents the same tools in a compact arrangement.

## Suggested walkthrough

1. **Start with the generated match.** [Open Eastbridge–Northport, 18 October 2026](https://counterpress.icyplant-0eb80d8e.eastus.azurecontainerapps.io/?match=synthetic-32fe41c5d304ce68d7d9#gi). Browse Overview and Moments, choose a goal and replay its build-up.
2. **Bring in the analysts.** From Watch full match, select Analyst Mode, or [open it directly](https://counterpress.icyplant-0eb80d8e.eastus.azurecontainerapps.io/?match=synthetic-32fe41c5d304ce68d7d9#analyst). Choose a player in the Player Analyst desk, set speed to **5×**, and play. Read a contribution and its reply; open the supporting evidence to connect the reading to a passage of play.
3. **Explore the full-time report.** Advance the replay to the end and open **Match summary**. Analysis starts automatically. Inspect each team's strengths, review points, pitch zones and suggested coaching work. Completed reports are reused.
4. **Keep a moment.** Return to Moments, select **Save to Highlights**, then open the saved play. Read Footie's Summary, use **Red pen** to annotate a paused frame, and add a coaching note. [Highlights](https://counterpress.icyplant-0eb80d8e.eastus.azurecontainerapps.io/#highlights) also contains preloaded examples.
5. **Make it personal.** In [Clubhouse](https://counterpress.icyplant-0eb80d8e.eastus.azurecontainerapps.io/#football), follow a player or club, open a profile and inspect its statistics, activity map and history. Compare players or explore the standings.
6. **Ask a question.** Open [Footie](https://counterpress.icyplant-0eb80d8e.eastus.azurecontainerapps.io/#assistant), or use Ask Footie from a profile or supported moment. Try “Who has supplied the most assists for Redhaven?” and inspect the supporting records.

## Reading the analysis

Commentary is generated asynchronously and labelled with the match time it analyzes. Faster replay advances the game faster than model responses arrive; quiet spells can pass without a new comment. The latest accepted finding stays visible and earlier contributions can be expanded. A report can take longer than a short comment because it considers the full match.

The generated match and careers demonstrate new calibrated synthetic events. The 16 and 17 October fixtures are adapted licensed reference matches with fictional identities. [Data provenance and methodology](../README.md#data-and-scope) explain the distinction. Pitch movement is reconstructed; event maps describe recorded actions rather than measured continuous tracking.

## Browser storage and recovery

- Favourites, saved highlights, drawings and notes belong to the current browser and site. Use the same browser to revisit them. Private browsing or blocked storage can prevent persistence.
- If the first load is slow, allow it to finish before refreshing. A model failure is reported explicitly; use the offered retry after the current request finishes.
- When switching matches, check the title and scoreboard. Statistics and agent requests follow the selected match; results from an earlier match are not carried into the new view.
- The demo video provides a guided walkthrough, while the live app remains the interactive judging experience.
